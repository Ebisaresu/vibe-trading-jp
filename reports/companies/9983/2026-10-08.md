## 4. 株価の反応

開示は10/8 15:31、取引終了(15:30)の直後。反応は翌営業日10/9の取引で出た。同日の日次記事: なし(10/8、10/9とも日次記事を作成していない)。

| 項目 | 値 | 根拠 |
|---|---:|---|
| 10/8 終値(開示前の最後の値) | 74,800円 | 前日比+0.03% |
| 10/9 始値 | 75,500円 | 前日終値比+0.94%。寄り付きは高かった |
| 10/9 高値 | 75,600円 | |
| 10/9 安値 | 71,620円 | |
| 10/9 終値 | 71,780円 | 前日終値比**−4.04%** |
| 10/9 出来高 | 2,126,700株 | 直近20営業日平均(1,129,095株)の1.88倍 |
| 同日の TOPIX連動上場投資信託(1306) | +0.70% | 指数の代理として使用 |
| 同日の日経平均 | −0.02% | |

- 値幅制限の確認: 基準値段74,800円は「70,000円以上100,000円未満」の区分で制限値幅は上下15,000円。下限は59,800円で、安値71,620円は届いていない。ストップ安ではない。
- ノイズの確認: 直近20営業日の前日比の絶対値平均は1.17%。当日の4.04%はその3.5倍で、通常の変動の範囲外。
- 市場との対比: TOPIX の代理指標が+0.7%の日に−4.0%。日経平均は値がさ株の寄与が大きい指数で、この銘柄の下げを受けてもほぼ横ばいだったことから、市場全体は上げていた日と読める。
- 寄り付きは高く、その後に売られた形(始値+0.9%→終値−4.0%)。
- 株探の見出しは「大幅反落、決算サプライズ限定的で地合い悪に押される」(2026-10-09 14:50)、「軟調、27年8月期は事業益16%増を計画・年間配当は50円増配も」(同 09:22)。前者は因果を述べているので引用する。本メモの第1節・第5節の数字と整合する読み方は、実績は会社予想を上回ったが、今期の1株利益の会社予想がアナリスト予想平均を3.5%下回った点が材料視された、というもの。ただしこれは開示資料と見出しからの推論であり、会社が述べたものではない。

参考(算出値): 10/9終値71,780円は、今期の会社予想1株利益1,825.06円に対して39.3倍、前期実績1,768.08円に対して40.6倍。今期配当予想900円に対する利回りは1.25%。1株当たり親会社所有者帰属持分9,274.27円に対して7.74倍。
